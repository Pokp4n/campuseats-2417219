# Week 1 Reflection

## 1. What is the difference between imperative and declarative UI?

Imperative UI tells the program step by step how to change the interface, while declarative UI describes what the interface should look like. React uses declarative UI because we describe the UI using components and JSX.

## 2. Why must a React component name start with a capital letter?

A React component must start with a capital letter so React can tell the difference between our own component and a normal HTML element. For example, <Header /> is a React component while <header> is an HTML element.

## 3. What is the purpose of a Fragment compared with a div?

A Fragment lets us group multiple elements without adding an extra HTML element to the page. A div also groups elements, but it will add an actual <div> to the HTML.

## 4. What is the benefit of splitting the UI into small components?

Small components make the code easier to understand, manage, and reuse. It is also easier to update one part of the UI without changing the whole application.
